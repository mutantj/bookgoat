# Bookgoat

A browser word game in the spirit of the classic Bookworm, starring Rapunzel the goat.

## Play locally
```
npm install
npm run dev      # open the printed URL (add --host to try it on your phone over Wi-Fi)
npm test         # engine tests
```

## Builds
- `npm run build` → `dist/` for GitHub Pages (relative paths, works at `/bookgoat/`).
- `npm run build:single` → one self-contained HTML file in `dist-single/`.

## GitHub Pages
Push to `main`, then in the repo's **Settings → Pages** set **Source** to **GitHub Actions**.
`.github/workflows/pages.yml` tests, builds and deploys on every push.

## Layout
- `src/engine/` — game rules, no UI. `rules.ts` holds every tunable number.
- `src/ui/` — Rapunzel (SVG) and saving.
- `src/main.ts` — board rendering and input (tap, drag, keyboard).
- `src/data/enable1.txt` — ENABLE word list (public domain). `bonus.txt` — common words for the bonus word (generated by `npm run bonus-words` from SCOWL).
